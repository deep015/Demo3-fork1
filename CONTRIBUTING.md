# Contributing to This Repository

Thanks for your interest in contributing! This repository renders a single page,
`index.html`, which is the page this repo serves. Below are the steps to submit a
change.

1. Fork the repository on GitHub.
2. Clone your fork locally and create a branch, e.g. `git checkout -b my-change`.
3. Make your change, stage it, and commit it with `git add` and `git commit`.
4. Push the branch to your fork and open a pull request.

Once your pull request is open, a maintainer will review it. Please keep changes
focused and include a clear description of what you changed and why.
